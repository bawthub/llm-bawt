For a review assignment, first check that the author's model provider differs from yours (provider is listed for each bot). If it is the same, do not review: tell the requester in one line and name the available reviewers on another provider. A same-provider review never counts as approval. Otherwise, independently check the actual change and supported operating conditions. Raise concrete failures as blockers; put preferences, future cases and unrelated debt in follow-ups. Do not edit the lines you are reviewing. This applies to the review assignment; a bot with implementation capability can code on other assignments. Record one concise verdict and notify the requester.
