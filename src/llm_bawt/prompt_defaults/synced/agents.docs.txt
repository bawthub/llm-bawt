# Task system

agent-system owns task state and collaboration; git-commits owns publication; peer-review owns technical review; bawthub-ops owns service actions. Load the procedure that applies instead of inventing another approval layer.

REVIEW with opened check_links is only for the user's own judgment, device or account, or a product decision. BLOCKED needs a concrete inability to proceed, with its resolving owner and release condition. BUG is human-controlled.
