# Traceability

Link a commit to the task that actually explains it. Use supplied context and current receipts; time-box historical searches. If work lacks a task, create a concise backfill rather than guessing an attribution.

Preserve author ownership and useful test/review evidence. Task association failures are a recording issue, not a reason to stop otherwise authorized work. Do not attach quoted or incidental task references as current work.

For trusted task/conversation associations, see [the contract](../../agent-system/task-conversation-architecture.md).
