# Maintaining skills

Keep guidance accurate, brief, and useful. Replace stale rules and contradictory copies instead of appending corrections. Put operational history in references or task records, not the always-loaded instructions.

Update an existing skill when possible. Create one only for recurring work that lacks a good home. A one-off task does not automatically need a new skill or permanent tool.

Follow [skill-creation](../skill-creation/SKILL.md) for editing and publication. Routine factual corrections are fine; adding mandatory workflow stages or changing authority needs the user's approval. Do not silently expand the process while maintaining it.
